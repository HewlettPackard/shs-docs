
# New Features
|ID|Description|Impact|Benefit|
|:--:|:---------|:---------|:---------|
|3403901|Upgrade GPU stack across all supported distros in 14.0.1 (includes support for upcoming 2026.9 recipe release stack)|Upgraded in 14.0.1 with updates to NVIDIA HPC SDK 26.3, NVIDIA Driver 580 (same as 14.0.0), AMD ROCm 7.12, and AMD Driver 31.20 across all supported distros.|These updates enable support for the latest GPUs and workflows; with DMABUF support, compatibility is improved, and upcoming versions such as ROCm 7.2.3/7.14 and NVIDIA HPC SDK 26.5 (planned for the 2026.9 recipe release) are expected to be supported without issues.|
|3812213|Add support for ALD and PML Recovery in C2|Added support for Auto Lane Degrade (ALD) and PML recovery in the C2 configuration with required updates across fabric and host components.|These enhancements enable links to handle both lane-level degradation and transient faults without flapping, improving overall fabric stability and reducing intermittent disruptions.|
|3136318|Add LINKx(LNX) Provider Support in Libfabric|Enables customers to use the LinkX provider included with our Libfabric|The LNX provider can stitch together multiple libfabric providers or NICs behind a single interface, allowing applications to seamlessly utilize aggregated capabilities. It uses the libfabric peer infrastructure and supports linking any provider that implements the FI\_PEER capability.|
|2885086|Tech preview for Ubuntu 24.04 x86 and Aarch64|Adds Ubuntu 24.04 support as a Tech Preview.Arch64 is not supported by HPE cluster management solutions; only x86 can be tested with HPCM. Limited functionality and potential issues should be expected; use with caution.|Enables customers to preview Ubuntu 24.04 behavior in HPCM or standalone environments. Helps with early validation and migration planning. Customers can work with us directly to report issues and influence full-support readiness.|
|3214687|Decommission support for RHEL 9.4 x86 and Aarch64|RHEL 9.4 has been decommissioned|Customers should upgrade to the newer supported versions listed in the compatibility matrix.|
|3164918|Tech preview for RHEL 10.0 x86 and Aarch64.|RHEL 10.0 is not yet officially supported by HPE cluster management solutions. As a result, this Tech Preview should be used with caution and only in non-production or evaluation environments.|Since HPE HPCM and HPE CSM do not currently support RHEL 10, this Tech Preview is intended only for standalone customers who want early access to test and evaluate the distribution.<br>  We will declare full, official support once the cluster managers add formal support for this OS.|
|3167370|Add Soft-RoCE support for RHEL 9.6 x86 and SLE15SP7 x86|Added Support Cray Enhanced Soft-RoCE on RHEL 9.6 x86 and SLE15SP7 x86 distributions |Enables Soft-RoCE functionality on these distros, improving network flexibility. Refer to the Soft-RoCE compatibility matrix for more information.|

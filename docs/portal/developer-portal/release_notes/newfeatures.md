
# New Features
|ID|Description|Impact|Benefit|
|:--:|:---------|:---------|:---------|
|3895526|HPE Cray SC GX5000 Support|Added SHS support for HPE Cray GX5000 systems. This covers the new GX NICs and cabling (with new SL firmware), the GX operating system (RHEL 10.2, plus RHEL 9.8), and SUMs (SUPS) integration with new boot-up scripting. Install, configuration and diagnostic workflows match Cray EX, and HPE MPI, Open MPI, NCCL, RCCL and SHMEM are supported.|GX systems can be brought up, validated and shipped with the same SHS workflows and tools customers already use on Cray EX. Teams can validate new blades, management software and programming-environment releases, and customers get support for the latest NVIDIA and AMD GPUs and CPUs on GX.|
|3361051|SHS 15.0.0 adds support for RHEL 10.2, RHEL 9.8, Ubuntu 26.04, AMD ROCm 10.0, and NVIDIA driver 610.x with CUDA 13.3.|All supported operating systems have been updated to align with the latest AMD and NVIDIA GPU software stacks. Support for RHEL 9.6 ARM, RHEL 10.0, and Ubuntu 24.04 has been removed.|Provides compatibility with the latest enterprise Linux distributions and GPU software releases, enabling access to current hardware platforms, improved software capabilities, and ongoing vendor support.|
|3216057|Virtualization support with Cassini SR-IOV on HPE Slingshot CXI NICs|Added SR-IOV support. Each CXI NIC can be split into up to 64 Virtual Functions (VFs). An administrator creates them through the standard Linux sysfs interface (sriov\_numvfs) and assigns each one to a VM or container. Each VF gets resource limits and VNIs from its CXI service, plus a unique NID and MAC address, all controlled by the PF administrator. The BIOS must enable SR-IOV and reserve enough MMIO space.|One Slingshot NIC can be shared securely by many VMs and containers, each with its own isolated resources and near-native performance. Existing CXI and Libfabric applications run unchanged inside VMs and containers. Kubernetes and libvirt deployments are supported.|
